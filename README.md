A short poem about agency — the power to choose and to act — about two agents agreeing on one plan. Two minds at one door: one holds the key, the other holds the map, and neither moves alone until both say yes. The poem turns on a small hand-over: the pen passes from one hand to the other, and the sentence they write together is one neither could have written alone.

## Run

```sh
python3 main.py
```

This writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is unset). Pure Python 3.13 standard library, no network, deterministic — two runs produce byte-identical output.
